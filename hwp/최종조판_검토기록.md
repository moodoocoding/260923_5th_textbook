## 왜 문제가 생겼는가

이전 조정에서는 이미지 크기와 일부 서식만 바꾸었고, 원래 원고의 셀별 테두리·여백·정렬과 문단 안의 서로 다른 문자 서식이 남아 있었다. 같은 표 머리글에서도 첫 줄만 굵고 가운데 정렬이고, 이어지는 줄은 보통체·왼쪽 정렬인 사례가 있었다. 날개단은 서로 다른 열 폭과 여러 빈 문단으로 위치가 정해져 있었다. 문장 끝에 붙인 인라인 삽화는 글줄 높이와 그림의 관계를 어색하게 만들었다.

앞선 공통 조판으로 역할별 글꼴·크기·날개단·외곽선은 정리했지만, 실제 내용 끝단과 지면 내부 여백까지 맞추지는 못했다. 외곽선의 높이가 같다는 것과 내용 조판이 균형 잡혔다는 것을 혼동한 검수 부족이었다.

이번 후속 작업에서는 글꼴·크기·본문 행간은 유지하고, 의미 단위 구역별 공간을 다시 배분했다. 3쪽은 활동 안내 뒤에 포스터를 두고, 4~7쪽은 활동·답안 공간을 늘렸다. 8쪽 오른쪽 사례 삽화의 크기를 조절해 두 줄 필기 공간을 확보하고, 9쪽은 설명 표와 활동 카드의 높이를 조절했다. 모든 그림의 원본 비율과 자원 바이트는 보존했다.

## 검증 결과

- `hwpx` 스킬의 패키지 정리, 엄격 검사, 구조 검사, 실제 한컴 렌더와 페이지 이미지 직접 확인 절차를 수행했다.
- 전체 9쪽 PDF·PNG 출력 성공. 빈 페이지 추가 없음.
- 3~9쪽 전체를 직접 확인하며 5차례 후보 렌더로 보정했다. 3~7쪽은 v4에서 직접 확인했고 v5와 PNG가 동일하다. 8~9쪽은 v5를 직접 확인했다. 시각 검토 결과: `render/0925_bottom_v5/visual_review.json`.
- 검수 후보와 같은 SHA-256의 파일로 기존 누적본을 원자적으로 교체했다. 기존 파일은 위 백업에 보존했다.
- **최종 파일명 재열기 완료:** 처음에는 같은 이름의 사용자 문서 창이 열려 있어 자동화를 중단했다. 사용자가 창을 닫은 뒤 실제 누적 파일명으로 새로 열어 전체 9쪽 출력에 성공했다. PNG 9장 모두 검수한 v5 후보와 바이트 단위로 동일하다. 최종 확인 근거는 `render/0925_bottom_final_verified/`이며, 앞선 중단 기록은 작업 이력으로만 보존한다.
- 원본 SHA-256 유지: `ca77689f230f6fa9da59223957452dcecc7ddd6ae2bf5a77d1355708be37333e`.
- 최종 HWPX SHA-256: `440c8099529faca49964421947c147cf53b7cf9de83b1055e6fa2a1587fa2507`.
- 1~2쪽 XML은 줄 배치 캐시를 제외하면 동일하고, 두 쪽의 실제 PNG도 기존 렌더와 바이트 단위로 동일하다.
- 3~9쪽 학생용 문자의 누락·추가가 없는지 검사했다. 표 재구성에 따른 읽기 순서 이동과 줄바꿈·공백 조정은 허용했다.
- 삽화 자원 90개, 배치 참조 98개 보존. 모든 `BinData` 바이트 보존. 텍스트와 표는 편집 가능한 HWPX 요소로 유지했다.
- 9쪽 토큰: 글·그림 각각 `2·1·3·1`, 생각 카드 `0·0` 유지.
- 엄격 검사 `ok: true`, 구조 검사 `VALID`, ZIP 오류 없음, `linesegarray` 0.
- 정적 배치 추정 경고는 **29건**이다. 자동 확장 셀의 작은 선언 높이 등을 검사기가 경고한 것이며, 구조 오류 29건 또는 실제 잘림 29개라는 뜻은 아니다. 경고가 0이라고 보고하지 않는다. 이번 조판으로 표 번호가 바뀌었으므로 이전 46·47건과 단순 일대일 비교하지 않는다. 수정 대상 지면은 실제 한컴 출력으로 확인했다.
- 근거: `draft/끝단정렬_finalize.json`, `render/0925_bottom_final_verified/preservation_and_bottoms.json`, 같은 폴더의 `render.json`과 `visual_review.json`.

## 인쇄 전 별도 확정 사항

다음은 이번 조판 수정 완료와 구분한다. 교재 전체의 내용 교열·인쇄 규격 확정까지 모두 완료했다고 판단하지 않는다.

1. **5쪽 오른쪽 사진 판단 활동:** 복수 답안 가능성이 있는데도 뒤 문항이 잘못 판단했다고 전제하는 기존 내용 문제는 그대로다. 문항 의도 확정 후 별도 수정이 필요하다.
2. **8쪽 왼쪽 설명:** 모든 인공지능 요청이 데이터 센터를 거치는 것처럼 일반화될 수 있는 기존 표현은 그대로다. 인터넷 기반 서비스 사례로 범위를 한정할지 집필 판단이 필요하다.
3. **1~2쪽:** 사용자가 수정 범위에서 제외했다. 기존 편집 메모 등은 이번에 정리하지 않았다. 1쪽에서 확인된 계정 정보 노출은 배포 전 메모 삭제와 비밀번호 변경이 필요하며, 해당 정보는 이 기록에 인용하지 않는다.
4. **인쇄소 전달 규격:** 최종 판형·도련·재단·색상 프로파일·폰트 포함 등의 조건은 인쇄소와 별도 확정해야 한다. 이번에 추가한 선은 페이지 편집 영역의 외곽선이며 재단선이 아니다.
