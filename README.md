2026-09-26 공개용 사본은 검수된 누적본에서 **1쪽 계정 정보 메모만 제거**하고 문서 미리보기를 새로 생성한 파일입니다. 3~9쪽의 XML·삽화 바이트·실제 한컴 렌더는 누적본과 같습니다. 원본과 비공개 누적 작업본은 로컬에 그대로 보존했습니다.

HWPX는 그림 화질을 낮추지 않고 Git LFS로 보관합니다. GitHub 파일 화면의 다운로드 기능을 사용하거나 Git LFS가 설치된 환경에서 다음 명령으로 받습니다.

```sh
git clone https://github.com/moodoocoding/260923_5th_textbook.git
cd 260923_5th_textbook
git lfs pull
```

## 보관 범위

- `docs/`: 기존 기준 원고와 쪽별 검토 문서
- `pic/`: 현재 삽화 및 캐릭터 기준 시트
- `hwp/`: 누적 조판 지침·사용 이력·디자인 규격
- `hwp/publish/`: 민감 메모를 제거한 공개용 HWPX와 PDF
- `scripts/prepare_publication.py`: 로컬 누적본에서 공개용 사본을 만드는 보조 스크립트

계정 정보가 포함된 0925 원본·내부 누적본, 기존 `최종안.pdf`, 시안, 백업, 임시 렌더는 이번 업로드에서 제외합니다. 검토 기록에 나오는 `draft/`, `render/` 및 내부 누적본 링크는 로컬 작업 이력이며 GitHub에는 포함하지 않습니다. 공개용 사본은 배포용이며 기존 단일 누적 편집본을 대체하지 않습니다.

## 인쇄 전 남은 사항

1~2쪽의 일반 편집 메모·임시 표기는 조판 수정 범위가 아니므로 남아 있습니다. 5쪽 사진 판단 문항과 8쪽 데이터 센터 설명의 내용 검토도 별도 확정이 필요합니다. PDF는 한컴 조판 확인용이며 PDF/X·도련·색상 프로파일 등 인쇄소 납품 규격을 보증하지 않습니다.

과거 노출된 계정의 비밀번호는 파일에서 삭제하는 것과 별개로 변경해야 합니다.
