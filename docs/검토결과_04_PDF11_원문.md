## 2. 상세 검토

### P11-01 - 서로 겹치는 분류 기준

**영역:** ③ 논리·⑤ 학년·⑦ 활동 / 수정 권고·중요.

주문·운반·계산은 이야기에서 기기가 맡게 된 일이므로 ‘많이 달라진 일’로 설명할 수 있습니다. 동시에 주문 오류, 음식을 제대로 받았는지, 결제 오류는 사람이 살펴야 할 수 있습니다. 따라서 ‘많이 달라진 일’과 ‘여전히 사람이 살펴야 할 일’은 배타적인 세 칸이 아닙니다. 원문이 복수 분류를 명시하지 않아 어느 칸에 써야 할지 혼란이 생깁니다.

원문 2번이 서로 다른 생각의 이유를 묻는 점은 장점입니다. 그렇다고 분류의 두 기준을 섞은 문제가 자동으로 해결되지는 않습니다. 서두 표처럼 변화 정도와 사람이 할 일을 나누어 적게 하는 안을 권고합니다. 더 작은 수정으로 유지하려면 “한 일이 여러 칸에 들어갈 수도 있습니다. 넣은 까닭을 설명해 봅시다.”를 넣을 수 있습니다. 두 안을 동시에 적용할 필요는 없습니다.

메뉴 추천 방식과 손님 불편 처리 방식의 전후 변화는 이야기에서 설명하지 않습니다. ‘조금 달라졌다’고 보는 답은 가능한 가정을 밝힌 경우의 답이지, 원문으로 입증된 유일한 정답은 아닙니다. 일부 칸이 비어 있어도 오답으로 처리하지 않습니다.

### P11-02 - 생각이 같을 때의 응답 경로

**영역:** ③ 논리·⑦ 활동 / 수정 권고.

친구와 생각이 반드시 달라진다는 조건은 없습니다. 일치한 판단의 근거도 설명할 수 있도록 대체 지시를 넣습니다. 가상의 반대 의견을 꾸며 실제 친구의 생각처럼 기록하게 해서는 안 됩니다. 한 문항에서 일 선택·두 사람의 판단·이유 비교를 수행하므로 항목별 틀을 유지하는 것이 5학년에게 도움이 됩니다.

### P11-03 - 인공지능·로봇·자동화의 구분

**영역:** ① 개념·② 근거·⑤ 학년 / 수정 권고.

가게 이야기의 키오스크·서빙 로봇·자동 결제기는 실제 AI 사용 여부나 기능을 특정하지 않습니다. 인공지능과 로봇 기술을 함께 다룬다는 도입 자체는 타당하며, 모든 로봇이나 자동 기기가 AI가 아니라고 단정하는 것도 부적절합니다. [OECD 정의 해설 S1][S1]의 추론·출력 기능을 기준으로 볼 때 기기의 이름만으로 분류하기는 어렵다는 판단입니다.

서두의 추가 설명으로 사례의 범위를 분명히 하거나, 집필자가 확인한 AI 기능을 구체적으로 적어야 합니다. 예를 들어 ‘물건의 모습을 알아보아 계산을 돕는 기능’처럼 쓰려면 이야기 속 결제기도 그 기능을 쓰는 가상 조건으로 수정합니다. 실제 분식집이나 제품의 도입 효과를 조사한 것처럼 제시하지 않습니다.

### P11-04 - 변화와 피해, 개인과 사회의 역할 구분

**영역:** ③ 논리·⑥ 목표·⑧ 균형 / 수정 권고.

일하는 모습이 바뀌는 것에는 편리함, 새로운 업무, 적응의 어려움 등이 있을 수 있습니다. ‘달라지는 문제’라는 선택지와 ‘내가 조심해야 할 것’이라는 질문만으로는 학생이 무엇을 실천할지 불분명합니다. 학생은 도움이 필요한 손님을 살피거나 어른에게 도움을 요청할 수 있지만, 고용·교육·기기 접근성을 혼자 해결할 수는 없습니다.

원문은 직원이 실제로 해고되었다고 말하지 않습니다. 따라서 ‘예전 직원은 모두 일자리를 잃었다’를 정답으로 만들지 않습니다. [ILO의 2025년 연구 요약 S2][S2]도 생성형 AI에 대한 노출과 실제 일자리 상실을 구분하는 참고가 됩니다. 이 자료는 로봇 분식집의 실제 변화나 여섯 일의 정답을 입증한 연구가 아닙니다.

### P11-05·06 - 따옴표와 자기 점검

**영역:** P11-05 ④ 어문 / 필수. P11-06 ⑥ 목표·⑦ 활동 / 선택.

준서의 대사는 끝에 여는 큰따옴표가 있어 짝을 맞춰야 합니다. 지면과 추출 문자에서 확인한 오류입니다. 다른 대사의 직선 따옴표는 그 자체로 오탈자로 세지 않고 편집 모양 통일 대상으로 둡니다.

마지막 세 문장은 학생의 자기평가로 성립합니다. 전부 체크해야 정답이라는 활동이 아닙니다. 실제 수행을 확인하고 싶다면 한 항목의 설명을 추가로 받습니다. 03차시 목표인 ‘문제의 영향을 말하기’는 오른쪽 영향 표로 이미 확인할 수 있으므로 P11-06을 필수 누락으로 보지 않습니다.

## 3. 모든 활동의 풀이와 허용 답안

### 가. 일 여섯 가지 분류

다음은 원문의 이야기로 가능한 풀이입니다. 사례는 가상 상황으로 읽으며, 기기 도입 이후 모든 업무의 변화가 주어졌다고 가정하지 않습니다.

| 활동 ID·일 | 현재 원문에서 가능한 판단 | 사람이 살펴야 할 점·복수 답의 근거 |
|---|---|---|
| L1-㉠ 손님의 주문을 받는 일 | 키오스크가 주문을 받으므로 ‘많이 달라짐’ 가능 | 주문 오류나 사용의 어려움을 살피는 역할도 가능 |
| L1-㉡ 음식을 자리까지 가져다주는 일 | 서빙 로봇이 가져다주므로 ‘많이 달라짐’ 가능 | 잘못 배달되거나 통로에 문제가 있을 때 확인·도움 필요 |
| L1-㉢ 음식값을 계산하는 일 | 자동 결제기를 이용하므로 ‘많이 달라짐’ 가능 | 계산·결제에 문제가 생기면 사람의 확인도 필요 |
| L1-㉣ 손님의 불편을 듣고 해결하는 일 | 도입 후 방식이 없어 변화 정도는 확정 불가. ‘사람이 살펴야 함’은 합리적 | 상황을 듣고 해결을 돕는 일. 다른 분류도 가정·근거가 있으면 허용 |
| L1-㉤ 손님에게 어울리는 메뉴를 추천하는 일 | 추천 기능 도입 여부가 없어 변화 정도는 확정 불가 | 사람이 추천할 수도, 추천 시스템을 참고할 수도 있음. 원문 밖 가정임을 표시 |
| L1-㉥ 기계를 사용하기 어려운 손님을 도와주는 일 | 기기가 도입되어 도움의 내용이 달라졌거나 새롭게 필요해졌다고 설명 가능 | ‘많이 달라짐’과 ‘사람이 살펴야 함’에 동시에 해당 가능 |

**반례:** ㉠을 ‘많이 달라짐’에 넣은 학생과 ‘여전히 사람이 살펴야 함’에 넣은 학생은 각각 기기의 담당 업무와 오류 대응을 기준으로 삼았을 수 있습니다. 어느 한 답을 무조건 오답으로 삼지 않습니다. ‘조금 달라진 일’에 넣을 항목 수를 채우기 위해 근거 없는 답을 강요하지 않습니다.

| L2-a 생각이 달랐던 일 | 주문을 받는 일 | 실제 친구와 대화한 뒤 선택. 의견이 같으면 P11-02의 대체 경로 필요 |
| L2-b 나의 분류 | 많이 달라진 일 | 키오스크가 주문을 받는다는 이야기 근거 |
| L2-c 친구의 분류 | 여전히 사람이 살펴야 할 일 | 오류와 사용 도움에 초점을 두었다는 설명 가능 |
| L2-d 달랐던 까닭 | 나는 주로 누가 주문을 받는지를, 친구는 도움이 필요한 상황을 생각했다 | 분류 이름 반복보다 서로 다른 판단 근거를 설명. 실제 친구 답을 존중 |

### 다. 사회 문제 선택·영향·실천

R1은 다섯 가지 중 하나를 선택하는 자기 판단 문항입니다. 유일한 정답은 없으며, R2의 ‘문제·영향·실천’ 세 칸과 R3의 약속이 서로 이어져야 합니다.

| R1 선택지 / R2 문제 | R2 사람들에게 생길 수 있는 영향 예 | R2 내가 실천할 수 있는 일 예 |
|---|---|---|
| 추천 영상만 계속 보는 문제 | 다른 주제·관점을 접할 기회가 줄어들 수 있음 | 다른 자료도 찾아보고 어떤 내용을 보고 있는지 점검 |
| 치우친 자료로 잘못 판단하는 문제 | 억울한 평가나 불편을 겪을 수 있음 | 결과만으로 사람을 단정하지 않고 근거를 확인하거나 어른에게 도움 요청 |
| 인공지능과 로봇으로 일하는 모습이 달라지는 문제 | 새 기기를 배우거나 다른 업무에 적응해야 할 수 있음 | 이용에 어려움이 있는 사람을 살피고 직원·어른에게 도움 요청 |
| 인공지능이 만든 가짜 사진과 거짓 정보 | 잘못된 정보를 믿거나 다른 사람에게 피해를 줄 수 있음 | 믿을 만한 출처와 대조하고 확인 전에는 퍼뜨리지 않음 |
| 인공지능에게 지나치게 의지하는 문제 | 스스로 생각하거나 사람과 이야기할 기회가 줄 수 있음 | 먼저 생각하고 중요한 고민은 믿을 만한 사람과도 이야기 |

위 내용은 허용 답안 예시입니다. ‘추천은 모두 해롭다’, ‘AI가 바꾸는 일은 모두 없어진다’, ‘가짜 사진은 외모만 보면 항상 알 수 있다’는 식의 일반화를 정답으로 요구하지 않습니다. 본 보고서는 9쪽의 가짜 정보·챗봇 활동을 정밀 검토한 결과가 아닙니다.

R3의 예: “나는 인공지능을 사용할 때 **알려 준 내용을 믿을 만한 자료와 비교한 뒤 공유하도록** 하겠습니다.” 선택한 문제와 관련되고 학생이 실제로 할 수 있는 행동이면 다른 답도 허용합니다.

### 라. 자기 점검 세 문장

| 활동 ID | 확인할 수행 | 답의 성격 |
|---|---|---|
| R4-a 결과를 바로 믿기보다 한 번 더 생각 | 왜 확인이 필요한지, 무엇을 확인할지 설명 | 자기평가. 체크 유무 자체로 정오 판단하지 않음 |
| R4-b 정보가 사실인지 확인 | 공식 안내·신뢰할 자료와 비교하는 방법 설명 | 외형 관찰만으로 사실 검증이 끝났다고 보지 않음 |
| R4-c 다른 사람에게 미칠 영향 생각 | R2에서 선택한 문제와 영향 연결 | 긍정·부정의 가능성을 조건에 맞게 설명 가능 |

**수업 전제:** 교재·필기도구·친구와 대화할 기회가 필요하며 실제 키오스크나 AI 계정은 필요하지 않습니다. 혼자 하는 경우에는 교사가 제시한 다른 관점을 비교하는 대안을 둘 수 있습니다. 배정 시간·실제 학생 수행·교육과정 성취기준은 제공되지 않아 적합성을 확정하지 않았습니다.
