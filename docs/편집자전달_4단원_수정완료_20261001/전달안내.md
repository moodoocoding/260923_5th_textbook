# 편집자 전달 안내

## 전달 내용

이 묶음은 `초등5_인공지능리터러시_4단원_12쪽수정완료.hwpx`에 사용된 이미지와 배치 정보를 편집자에게 함께 전달하기 위한 것이다. 원고·그림의 내용을 새로 고치거나 그림을 다시 제작한 작업은 아니다.

## 편집자가 확인할 순서

1. ZIP 전체를 풀고 폴더 구조를 유지한다. Markdown만 따로 옮기면 이미지 링크가 끊긴다.
2. [수정완료 HWPX](./01_원고/초등5_인공지능리터러시_4단원_12쪽수정완료.hwpx)를 연다. 글꼴·환경에 따라 화면이 달라질 때는 [실제 한글 내보내기 PDF](./01_원고/초등5_인공지능리터러시_4단원_12쪽수정완료.pdf)와 비교한다.
3. [이미지 배치 목록](./이미지_배치목록.md)에서 펼침 쪽수·왼쪽/오른쪽·세부 위치를 찾고 연결된 이미지 파일을 사용한다.
4. [원본 이미지 미리보기](./이미지_미리보기.md)와 [자르기 설정](./이미지_자르기설정.md)을 함께 확인한다.

## 쪽수와 파일명

쪽수는 전달 HWPX/PDF의 아래쪽에 인쇄된 펼침 지면 번호 1~12이다. 각각 왼쪽 페이지와 오른쪽 페이지를 구분한다. 기존 `pic` 파일명에 적힌 과거 쪽수는 전달용 이름에 사용하지 않았다.

여러 지면에서 반복 사용하는 활동 연필은 `공통_양쪽_활동연필아이콘_image13.png` 한 파일로 전달하고 11곳의 사용 위치를 기록했다. 한 지면의 양쪽에 쓰는 그림은 파일명에 `양쪽`을 사용한다.

## 검증과 보존

- 한글 내부에서 실제 참조되는 이미지 77종을 모두 확보했고 89개의 삽입 위치를 기록했다.
- 모든 전달 이미지의 바이트와 SHA256은 HWPX 내부 파일과 동일하다. PNG 76개와 BMP 1개이며, 색상·알파 채널·픽셀 크기를 바꾸지 않았다.
- 원고 HWPX와 확인 PDF는 기존 수정완료본과 바이트 단위로 동일한 복사본이다. 이번 포장 작업에서 원고를 재저장하지 않았다.
- 전달 이미지와 Markdown 링크의 누락 여부를 검사했다. 한글 그림 참조 수와 PDF의 실제 그림 배치 수가 모두 89개임을 대조했다.
- 기존 한글 렌더링의 입력 SHA256과 이번 전달 원고의 SHA256이 일치한다. 원고가 같으므로 그 렌더링 결과를 기준으로 배치를 확인했다.
- 기존 `pic` 원본과 이전 작업 파일은 이동·삭제하지 않았다.

## 편집 시 유의 사항

- `image25`는 원고에 121×189px BMP로 들어 있다. 큰 크기의 인쇄에 사용할 고해상도 원본이 필요한지는 편집자가 판단해야 한다.
- 원고의 자르기 설정이 있는 5종도 **전체 원본 이미지**를 전달했다. 조판 시 필요한 자르기를 별도로 적용한다.
- 원고에 포함된 문구·사진·삽화는 기존 상태 그대로 전달했다. 기존 1~11쪽의 내용 교정이나 삽화 속 문구 수정, 저작권·사용 허가 검토까지 완료했다는 뜻은 아니다.
