# 원고의 이미지 자르기 설정

원본 이미지를 잘라서 새 파일로 만들지 않았다. 아래 **5종은 현재 한글 지면에서 자르기 설정을 사용**하므로, 원고와 같은 구도를 재현하려면 조판 프로그램에서 별도로 자르기를 적용한다.

범위는 원본 이미지 왼쪽 위를 `(0, 0)`으로 보았을 때의 **왼쪽·위쪽·오른쪽·아래쪽 좌표(px)**이다. 한글의 `imgClip`과 `imgDim`에서 환산한 참고 수치이며, 소수점·조판 비율은 원고 및 지면 미리보기로 최종 확인한다.
