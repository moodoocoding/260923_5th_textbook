## Git으로 받는 경우

이 저장소는 전달 ZIP과 한글 원고를 Git LFS로 관리한다. Git LFS를 설치한 환경에서 다음 명령으로 받는다.

```powershell
git lfs install
git clone https://github.com/moodoocoding/260923_5th_textbook.git
cd 260923_5th_textbook
git lfs pull
```

일반 GitHub 소스 코드 압축 다운로드에 대용량 파일이 포함될 것이라고 가정하지 말고, 위의 전달 ZIP을 직접 내려받거나 Git LFS로 받는다.

7쪽 왼쪽의 학생 그림 1개는 기존 원고에 121×189px BMP로 들어 있던 저해상도 파일이다. 원본을 그대로 보존했으며, 인쇄용 고해상도 교체 여부는 편집 시 판단한다.

이 배포는 전달 자료 정리 작업의 결과를 공유하는 것이며, 기존 원고 전체의 내용 교정이나 저작권·사용 허가 검토가 완료되었다는 뜻은 아니다.
