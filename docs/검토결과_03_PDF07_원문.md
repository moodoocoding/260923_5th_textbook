## 1. 검토 범위와 핵심 판단

검토 대상은 PDF 7쪽의 03차시 「인공지능 사용할 때 한 번 더 생각하기」 도입과 추천 활동, 학습 데이터·편향 활동입니다. 학습 목표, 본문, ‘사회 문제’·‘학습 데이터’ 풀이, 카드 6개와 제작 설명, 모든 활동·하위 응답, 사진 제작 조건 7개, 캐릭터 질문, 원인·결과 문구 6개를 확인했습니다.

PDF 원문 지면을 렌더링해 전체와 작은 글씨를 확인했습니다. 오른쪽 선 잇기 문구는 추출 시 문자가 뒤섞여 나와 **실제 지면에서 판독**했습니다. 깨진 추출 문자나 글자 색을 원고의 오류로 집계하지 않았고, PDF 8쪽의 이미지 시안도 평가하지 않았습니다. PDF 1·2쪽은 차시명만, 9·11쪽은 차시 목표와의 연결을 확인할 범위만 읽었으며 해당 쪽 전체의 정밀 검토는 하지 않았습니다.

| 핵심 판단 | 이번 결과 |
|---|---|
| 추천 활동 | 카드와 이유를 연결하는 활동은 성립. 현재 질문은 열린 선택이므로 축구 카드만 정답으로 제한할 수 없음 |

## 3. 개별 검토 사항과 수정 근거

### P07-01 - 띄어쓰기 6곳

**판정:** ④ 어문 / 수정 필수.

서두의 여섯 위치를 교정합니다. ‘보고 있습니다’는 ‘-고 있다’ 구성이고, ‘차는 장면’·‘추는 사람’은 관형어와 명사가 구분됩니다. ‘연습 장면’·‘캐릭터 질문’은 해당 문맥의 일반 명사구입니다. ‘배우는 데 사용하는’의 ‘데’는 ‘배우는 일에 사용하는’이라는 뜻의 의존 명사입니다. [단어별 띄어쓰기 S1][S1]과 [의존 명사 ‘데’ 설명 S2][S2]를 적용했습니다.

여섯 위치의 붙임은 확대 지면과 문자 정보를 대조했습니다. ‘학습 데이터’처럼 원문에서 줄이 바뀌거나 글자 간격이 넓게 보이는 것을 별도 오류로 세지 않았습니다. ‘동그라미 해 봅시다’, ‘보여 주고’, ‘찾아봅시다’도 표현 선호만으로 필수 교정에 넣지 않았습니다.

### P07-02 - 본문 마침표와 대사 따옴표

**판정:** ④ 문장 부호 / 수정 필수, 2곳.

왼쪽 “사용하는 태도를 가져야 합니다”는 소제목이나 표제가 아닌 도입 문단의 끝이므로 마침표를 붙입니다. 문장 끝 마침표의 기능은 [국립국어원 S3][S3]를 확인했습니다.

오른쪽 “아하! 의사란 …” 응답 틀은 시작이 직선 큰따옴표이고 끝이 여는 큰따옴표 `“`입니다. 지면과 PDF 문자 코드에서 확인했습니다. 현재 문구를 유지한다면 양쪽을 `“…”`로 맞춥니다. P07-05처럼 응답 틀을 교체하면 이 교정은 새 틀에 포함하여 처리합니다. 활동 제목의 마침표 유무는 출판사 편집 기준으로 통일할 사항이며 본문 문장의 누락과 구분합니다.

### P07-03 - 인공지능 기능과 데이터 학습의 범위

**판정:** ① 개념·② 설명 범위·⑤ 학년 적합성 / 수정 권고.

왼쪽은 “서빙 로봇이나 자동 결제기”를 사례로 들지만, 그 이름만으로 AI가 어떤 판단을 하는지는 알 수 없습니다. AI를 쓰는 기기도 가능하므로 ‘자동 결제기는 AI가 아니다’라고 단정하지 않습니다. **무엇을 인식하거나 판단하는 기능인지**를 넣으면 자동화 전반과 AI 사례의 경계가 더 명료해집니다.

첫 문장의 기기 사례는 “물건의 모습을 알아보아 계산을 돕는 기기처럼 사람이 하던 일을 돕기도 합니다.”로 바꾸는 안입니다. 이는 특정 제품의 작동을 확인했다는 뜻이 아니라 AI 기능이 드러나는 예시 문안입니다. 11쪽의 키오스크·자동 결제기 사례에도 같은 쟁점이 있으므로 후속 검토에서 함께 확인합니다.

왼쪽 “인공지능은 수많은 데이터를 학습하여…”와 오른쪽 “인공지능은 … 스스로 규칙을 찾아냅니다”는 이번 학습 방식의 설명으로 이해할 수 있으나, 모든 AI가 같은 방식으로 학습하는 것처럼 읽힐 수 있습니다. [OECD의 정의 해설 S4][S4]는 기계학습과 지식 기반 접근을 구분합니다. 서두 표처럼 범위를 한정하고 ‘도출’을 ‘만듭니다’로 풀어 쓰는 안을 제안합니다.

왼쪽 문장의 ‘항상 옳게 느껴짐’은 실제 정확성을 보장하는 설명이 아니라 사용자의 인상에 관한 설명으로 읽어야 합니다. 뒤 문단이 오류 가능성을 이미 분명히 하므로 확정 사실 오류로 판정하지 않습니다. 제안한 ‘그럴듯하게 답한다’는 표현도 학생의 인상을 설명하는 문안이며, 모든 AI의 출력이 자연스럽다는 기술적 일반화로 사용하지 않습니다.

### P07-04 - 추천 활동의 단서와 허용 답안

**판정:** ③ 논리·⑤ 학년 적합성·⑦ 활동 / 수정 권고.

현재 “어떤 카드를 추천하고 싶나요?”는 추천자의 목적을 열어 둡니다. 축구를 보고 있으니 축구 관련 카드를 고를 수도 있고, 다른 경험을 주려고 과학·요리·춤 카드를 고를 수도 있습니다. 카드가 여섯 개라는 이유로 축구 세 장만 정답이라고 제한할 근거는 없습니다.

시청한 내용과 비슷한 영상을 추천하는 원리를 체험하려면, 첫 질문을 “준서가 지금 보고 있는 영상을 단서로, 이어서 보고 싶어 할 만한 카드를 골라 봅시다.”로 바꾸고 동그라미·이유 쓰기를 이어갑니다. 활동 아래에는 단순화한 가정임을 알리는 서두 표의 문장을 덧붙입니다. [YouTube의 공식 설명 S5][S5]에서 시청 기록 외 여러 신호를 사용하는 점을 확인했습니다. 이는 한 서비스의 사례이며 모든 추천 시스템이 같은 규칙을 쓴다는 뜻은 아닙니다.

현재 2번은 ‘계속 축구 영상만 추천받는다면’이라는 **가정**이므로 실제 서비스가 반드시 그렇게 작동한다고 주장한 것으로 보지 않습니다. ‘놓치게 될 수 있는 정보’라는 응답란의 가능성 표현도 적절합니다. 축구 자체가 나쁘거나 다른 주제를 완전히 볼 수 없어진다는 답을 유도하지 않습니다.

### P07-05 - 사진 활동을 조건이 드러나는 모의 활동으로 연결

**판정:** ① 개념·③ 논리·⑦ 활동·⑧ 윤리 / 수정 권고·중요.

다섯 의사 사진은 모두 흰 가운을 입은 남성입니다. 그러나 공통점이 같더라도 실제 모델의 학습 방식, 이전에 배운 내용, 정답 표시, 판단 기준 등이 없으면 두 새 사진에 대한 실제 AI의 답은 확정할 수 없습니다. 사진 5장이 부족하다는 수량 자체를 오류로 판정하지는 않습니다. 종이에서 간단한 판단 규칙을 흉내 내는 활동으로는 사용할 수 있습니다.

현재 1번에서 학생은 옷, 성별, 진료와 관련된 행동 등 서로 다른 특징을 고를 수 있습니다. 2번도 ‘예상해 봅시다’라고 했으므로 실제 역할에 맞는 답을 예상하는 학생이 있을 수 있습니다. 그런데 3번의 “왜 잘못 판단했는지”는 모두 같은 오답을 예상했다고 전제합니다. 첫째 사진을 ‘의사’, 둘째를 ‘의사가 아님’으로 예상한 학생에게도 성립하도록 질문을 고쳐야 합니다.

**권고하는 연결 문안**

| 위치 | 바로 사용할 수 있는 수정 문안 |
|---|---|
| 활동 도입 | 인공지능의 학습을 간단히 흉내 내는 활동입니다. 아래 다섯 의사 사진에서 공통으로 보이는 특징을 찾아봅시다. |
| 1번 지시 | 다섯 사진에서 공통으로 보이는 특징을 써 봅시다. |
| 1번 응답 틀 | 이 다섯 사진에서 공통으로 보이는 특징: (　　　　　　　　　) |
| 2번 지시 | 1번에서 찾은 특징만으로 의사인지 판단한다고 가정해 봅시다. 아래 두 사진에 어떤 답을 할지 예상하고, 그렇게 생각한 까닭을 말해 봅시다. |
| 3번 지시 | 1번에서 찾은 특징만으로 의사인지 판단하면 어떤 실수가 생길 수 있을까요? 처음 사진에 부족한 모습이나 정보를 찾아봅시다. |
| 3번 뒤 정리 | 실제 의사는 성별이나 옷차림만으로 판단할 수 없습니다. 다양한 모습과 하는 일을 담은 자료로 배우고, 새 자료에서도 알맞게 판단하는지 확인해야 합니다. |

학생이 ‘흰 가운’만 기준으로 삼으면 수술복 의사를 놓치고 흰 가운 선생님을 의사로 오인할 수 있습니다. 다른 기준을 고른 학생은 그 기준에 맞춰 설명하도록 합니다. 교사가 두 오답을 공통으로 비교하려면 2번에서 “이번에는 흰 가운을 입었는지만 보고 판단한다고 가정합니다”라고 **추가 가정**을 명시할 수도 있습니다. 이 규칙이 다섯 사진에서 반드시 학습된다고 설명해서는 안 됩니다.

치우친 다섯 사진은 편향을 발견하게 하려는 의도된 자료이므로 그 자체를 교재의 성차별 오류로 세지 않습니다. 다만 “의사란 … 사람”이라는 정의형 응답을 그대로 남기기보다 사진 속 공통점으로 한정하고, 성별·옷차림을 실제 직업의 기준으로 일반화하지 않도록 마무리하는 편이 적절합니다. 자료의 대표성과 실제 사용 환경에서의 점검 필요성은 [NIST S6][S6]를 참고했습니다. 다양한 자료를 추가하는 것만으로 공정성이 완전히 보장된다는 결론도 피합니다.

### P07-06 - 선 잇기의 원인과 결과 사이 설명 보완

**판정:** ① 개념·② 근거·③ 논리·⑤ 학년 적합성·⑦ 활동 / 수정 권고·중요.

현재의 대응은 채용 → 여성 지원자의 낮은 평가, 위험 예측 → 그 집단을 더 위험하다고 판단, 의료 → 아픈 사람의 도움 필요성을 낮게 판단입니다. 단어와 분야를 통해 연결은 가능하지만 **자료를 더 많이 보았다는 사실만으로** 특정 방향의 차별을 추론할 수 있는 것은 아닙니다. 원문 결과는 이미 ‘수 있습니다’라고 되어 있어 필연적 결과를 주장한 것으로 판정하지 않습니다. 가능성이 생기는 조건을 학생에게 더 제공하는 권고입니다.

세 원인 문구는 서두 표처럼 구체적인 **가상 조건**으로 바꿉니다. ‘채용’은 ‘직원을 뽑는 일’로 풀어 쓰고, ‘위험 예측’은 여기서 사람의 위험성을 평가하는 상황임을 드러냅니다. 특정 성별·집단이 실제로 능력이 낮거나 위험하다는 뜻이 아니라, 관련 없는 집단 특성으로 잘못 판단하는 사례라는 점을 분명히 합니다.

의료 사례에는 별도의 설명이 특히 필요합니다. “병원비 기록을 더 중요하게 봄”만으로는 왜 아픈 사람이 도움을 적게 받는지 알기 어렵습니다. 아파도 치료를 충분히 받지 못해 비용 기록이 작을 수 있다는 배경을 함께 제공합니다. 실제 연구는 건강상 필요 대신 비용을 예측한 알고리즘과 의료 접근성 차이의 문제를 다뤘습니다.[연구 초록 S7][S7] 원고의 실제 출처가 이 논문이라고 확정하지 않으며, 제안 문안을 뒷받침하는 사례로 사용합니다.

| 원인 쪽 수정 조건 | 유지할 결과 문장 | 학생이 설명할 연결 |
|---|---|---|
| 남성만 뽑았던 기록에서 남성과 관련된 특징을 높은 점수 기준으로 삼음 | 여성 지원자가 실력보다 낮게 평가될 수 있습니다. | 일할 능력과 관계없는 성별 관련 특징으로 점수를 매길 수 있음 |
| 어느 집단의 잘못한 사례만 배우고 집단에 속했다는 이유로 위험 점수를 높임 | 그 집단에 속한 사람을 실제보다 더 위험하다고 잘못 판단할 수 있습니다. | 개인의 행동을 충분히 보지 않고 집단 정보로 판단할 수 있음 |
| 아픈 정도 대신 병원비가 적은 사람을 도움이 덜 필요한 사람으로 판단함 | 많이 아픈 사람도 도움이 덜 필요하다고 잘못 판단될 수 있습니다. | 병원에 못 가 비용이 적은 아픈 사람을 놓칠 수 있음 |

원문은 세 사례를 모두 ‘치우친 자료’로 묶지만, 의료 사례에는 **무엇을 예측할 기준으로 삼았는가**라는 문제도 있습니다. 4번 첫 문장을 “인공지능이 치우친 자료로 배우거나 알맞지 않은 기준으로 판단하면 어떤 일이 생길 수 있을까요?”로 함께 고치는 안입니다. 이 문장과 가상 상황 안내, 원인 문구 세 개를 하나의 재구성으로 적용합니다.

### P07-07 - 차시명과 단원 안내의 명칭 연결

**판정:** ⑨ 원문 내부 일관성 / 수정 권고, 최종 명칭 결정 필요.

PDF 1쪽 목차와 7쪽 차시 제목은 “인공지능 사용할 때 한 번 더 생각하기”이고, PDF 2쪽 소단원 3 제목은 “인공지능 사회 문제 깊이 탐구하기”입니다. 2쪽이 의도적인 별도 안내 제목일 가능성을 배제하지 않으므로 확정 어문 오류로 집계하지 않습니다. 같은 소단원을 안내한다는 점에서는 명칭을 통일하는 편이 찾기 쉽습니다.

**통일안:** 1·7쪽 제목을 유지하고 2쪽 소단원 3 제목을 같은 문구로 바꿉니다. 다른 제목을 최종 채택하면 1·2·7쪽을 함께 갱신합니다. 제목에서 ‘인공지능’ 뒤 목적격 조사를 생략한 형식은 제목 표현으로 가능하므로 그 자체를 문법 오류로 처리하지 않습니다. 이 대조는 1·2쪽 전체 정밀 검토 완료를 뜻하지 않습니다.

### P07-08 - 생활의 영향을 말하는 응답 추가

**판정:** ⑥ 목표 연결 / 선택적 개선.

학습 목표는 문제 사례와 그 문제가 생활에 미치는 영향을 말하는 것입니다. 왼쪽은 놓칠 수 있는 정보, 오른쪽은 세 종류의 불리한 판단 결과를 다루므로 목표와 내용이 이미 연결됩니다. 다만 오른쪽 선 잇기만으로는 학생이 영향을 자기 말로 설명할 수 있는지 확인하기 어렵습니다.

4번 뒤에 “연결한 사례 중 하나를 골라, 그 사람의 생활에 어떤 불편이나 불이익이 생길지 말해 봅시다.”를 추가하는 안입니다. 예를 들어 ‘일할 기회를 놓칠 수 있다’, ‘잘못 의심받아 억울할 수 있다’, ‘필요한 돌봄을 받지 못할 수 있다’가 가능합니다. 11쪽에도 영향과 실천을 정리하는 활동이 있으므로, 이를 이번 페이지의 필수 누락으로 세지는 않습니다.

## 4. 모든 활동의 풀이와 허용 답안

아래는 **현재 원문 기준** 풀이입니다. 제작 지시대로 카드·사진이 제공된다는 전제이며, 정답 표시가 있는 완성 시안을 본 것은 아닙니다. 실제 모델을 실행한 결과와 학생의 모의 예상을 구분합니다.

## 6. 유지 가능한 내용과 연결 사항

| 항목 | 유지 판단 또는 후속 조치 |
|---|---|
| AI가 항상 정확하거나 공정하지 않다는 설명 | 오류·편향 가능성을 알리는 취지로 타당. 모든 AI가 항상 틀리거나 차별한다고 바꾸지 않음 |
| 추천이 관심과 관련된다는 설명 | 추천 활동의 출발점으로 적절. 하나의 시청 장면만으로 실제 추천이 결정된다고 확대하지 않음 |
| 치우친 자료를 배우면 잘못 알아볼 수 있다는 설명 | 조건부 가능성으로 타당. 특정 입력에서 무조건 오답이라는 결론과 구분 |
| 흰 가운 남성 의사 사진 5장 | 학습 자료의 편중을 관찰하기 위한 구성으로 유지 가능. 실제 직업의 정의로 굳히지 않도록 P07-05의 정리와 연결 |
| 실제 사진 대신 제작 설명이 있음 | 원고 단계에서 제공할 자료의 조건으로 검토. 시안의 그림 구현이나 해상도는 이번 대상이 아님 |
| 정답 사진의 실제 역할 | 원문이 T1을 의사, T2를 선생님으로 제시함. 사람의 실제 신원을 사진만으로 입증하라는 활동이 아님 |
| 세 사례 결과의 ‘수 있습니다’ | 위험의 가능성을 표현하므로 유지. 원인 조건을 P07-06으로 보강 |
| 1·2쪽 단원 안내 | P07-07의 제목만 연결 검토. 1·2쪽 나머지 어문·활동 검토는 예정대로 후속 수행 |
| 9쪽 거짓 정보·챗봇 사례 | 7쪽 도입에서 언급한 잘못된 정보와 과의존을 이어 다루는 구성임을 확인한 수준. 세부 판정은 9쪽 검토로 남김 |
| 11쪽 일의 변화 | 서빙 로봇·키오스크·자동 결제기 분류에서도 AI 기능과 자동화의 구분을 후속 확인할 필요가 있음 |
| 11쪽 영향·실천 정리 | 차시 목표를 뒤에서 종합할 활동이 있어, 7쪽에 완결된 모든 실천 활동이 없다는 이유로 누락 처리하지 않음 |
