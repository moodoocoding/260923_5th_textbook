- 왼쪽 페이지는 `딥페이크의 특징과 위험 알기 → 사진에서 의심 단서 찾기 → 출처와 사실 확인 방법 고르기 → 피해 대상과 영향 생각하기`로 이어진다. 서문과 활동이 직접 연결된다.
