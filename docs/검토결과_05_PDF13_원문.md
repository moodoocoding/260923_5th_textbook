## 2. 상세 판단

### P13-01 - 공유 활동의 반복과 차시 목표

**영역:** ③ 문맥·⑥ 목표·⑦ 활동·⑨ 일관성 / 구조 결정 보류·중요.

13쪽 오른쪽의 제목, 확인 기준, 포스터 활동 네 행, 정리 문장이 3쪽 오른쪽과 반복됩니다. 추출 순서는 줄바꿈과 날개단 위치 때문에 다르지만 의미 있는 본문·문항은 같은 구성임을 지면으로 확인했습니다. ‘복사 실수’였다고 집필 의도를 단정하지 않습니다.

04차시 목표는 환경·자원의 영향 설명과 지속 가능한 사용의 실천입니다. 공유 활동은 02차시 복습으로는 성립하지만, 현재는 복습 표시나 자원 학습과의 연결 안내가 없습니다. 특히 ‘동그라미 친 포스터’는 현재 왼쪽이 아닌 02차시에 있습니다. 이 상태로 그대로 두기보다는 A안 자원 활동 교체 또는 B안 명시적 복습 중 하나를 결정해야 합니다.

B안을 고르면 서두의 제목·참조 문장을 고치고, 자원 학습은 왼쪽과 15쪽에서 이어 간다는 연결을 교사용 지도에 명시합니다. A안은 4장의 교체 제안으로 검토할 수 있습니다. 어느 안도 원본에 자동 적용하지 않았습니다.

### P13-02 - 데이터 센터 경로와 정보 검색의 범위

**영역:** ① 개념·② 범위·③ 논리·⑤ 학년 / 수정 권고·중요.

4단계는 원격 서버에서 처리하는 서비스의 간단한 설명으로 성립합니다. 그러나 기기 안에서 실행되는 AI도 있으므로 모든 AI의 필수 경로로 가르치면 부정확합니다. [Apple의 기기 내·서버 모델 기술 설명 S1][S1]은 두 방식이 존재하는 직접 사례입니다. 특정 제품 사용을 권하는 것이 아니라 설명 범위를 확인하는 근거입니다.

‘정보를 찾아 처리’는 내부 정보 처리로 읽을 수도 있으나, 학생이 매번 인터넷에서 사실을 검색한 뒤 정답을 반환하는 것으로 오해할 수 있습니다. 최소한 ‘질문을 처리하여 답을 만든다’로 고칩니다. 검색 기능이 없는 AI가 아무 계산 없이 답한다는 뜻도 아닙니다. 그림에 적힌 학교 소개 글 요청은 흐름의 예시이며 실제 학교 정보의 정확성이 보장되지는 않습니다.

### P13-03 - 누적 자원 사용과 요청 한 번을 구분

**영역:** ① 개념·② 근거·⑤ 학년 / 수정 권고.

컴퓨팅과 통신에 전기가 필요하다는 핵심은 타당합니다. 다만 ‘모든 과정’, ‘수많은 컴퓨터’, ‘아주 많은 전기’가 이어지면 질문 하나에 항상 거대한 전력량이 소비된다고 받아들일 수 있습니다. [IEA S2][S2]의 시설 전체 전력 수요 설명은 요청 한 번의 고정 사용량이 아닙니다. [추론 에너지 연구 S3][S3]도 작업과 실행 조건에 따른 차이를 다룹니다.

수치를 임의로 붙이지 않고, 여러 이용의 누적과 작업별 차이를 짧게 밝히는 안이 적절합니다. 15쪽 활동 토큰과 실제 전기·물 사용량을 환산해서 설명하지 않습니다.

### P13-04 - 반복된 공유 기준을 남길 경우

**영역:** ③ 논리·⑦ 활동·⑧ 윤리 / 수정 권고.

[3쪽 검토본](검토결과_01_PDF03_원문.md)의 P03-03·04·05와 같은 문제를 현재 위치에서 다시 확인했습니다. 출처 안내는 틀렸다고 보기보다 이용 조건을 함께 보완할 부분입니다. [한국저작권위원회 공유마당의 라이선스 안내 S4][S4]는 출처 외에도 조건이 있을 수 있음을 보여 줍니다. 모든 자료에 개별 허락이 반드시 필요하다는 주장으로 바꾸지 않습니다.

시간 행은 문항에서 ‘실제와 다름’을 **주어진 가정**으로 삼아 조치 방법을 쓰는 활동으로는 풀 수 있습니다. 그러나 학생이 앞 포스터만 보고 실제 오류를 발견했다는 결론을 요구해서는 안 됩니다. 실제 시간으로 고치는 수행까지 요구하려면 학교 안내문을 추가해야 합니다.

닮은 얼굴은 걱정할 단서이나, 실제로 누구인지 알아볼 수 있는 조건과 같지는 않습니다. 알아볼 수 있는 정보로 명시하고, 필요하면 빼거나 다른 그림으로 바꾸고 공유 전 당사자·교사의 도움을 받는 답을 허용합니다. 개별 이미지의 법적 지위나 학생의 모든 AI 활용 표시가 법적 의무인지는 이 자료로 판정하지 않습니다.

### P13-05·06 - 어문과 문체

**영역:** ④ 어문·⑤ 표현·⑨ 일관성.

해요체와 합니다체는 모두 가능한 문체이므로 통일은 선택입니다. 제작 지시, 제목, 학습 목표까지 학생용 본문과 같은 종결어미로 기계적으로 바꾸지 않습니다.

## 4. P13-01 A안: 자원 학습으로 교체할 경우의 문안

**현재 원문의 정답이 아닌 선택용 재구성안**입니다. 오른쪽 공유 제목·표·날개단·포스터 활동·정리를 한 묶음으로 교체하는 범위이며, 채택 전에는 원본을 삭제하지 않습니다.

### 화면 밖의 일을 설명해 보아요

“왼쪽의 인공지능 서비스가 답을 만드는 과정을 살펴봅시다. 우리가 쓰는 화면뿐 아니라 화면 밖의 컴퓨터도 전기를 사용해요.”

1. 다음 카드가 일어나는 순서대로 번호를 써 봅시다: **답이 화면에 나타남 / 질문을 입력함 / 데이터 센터의 컴퓨터가 계산함 / 질문이 인터넷으로 전달됨**.
2. 순서대로 연결한 과정 중 하나를 골라, 어떤 기기가 무슨 일을 하는지 설명해 봅시다.
3. “화면에서 답을 받을 때에는 아무 자원도 쓰이지 않는다”는 생각에 어떻게 답하고 싶나요? 왼쪽에서 찾은 근거를 말해 봅시다.

정리: “인공지능을 이용할 때에는 기기와 컴퓨터가 전기를 사용해요. 다음 활동에서는 전기와 물의 사용, 그리고 필요한 도움을 알맞게 받는 방법을 알아보아요.”

**재구성안 풀이:** 제시 순서에 쓸 번호는 4·1·3·2. 2번은 예를 들어 ‘데이터 센터의 컴퓨터가 질문을 처리해 답을 만든다’, 3번은 ‘컴퓨터가 계산하고 질문·답을 주고받는 데 전기가 필요하다’가 가능합니다. 이 예시의 경로만 다루며 물·탄소의 상세 설명은 15쪽에서 이어갑니다. 실제 AI 계정은 필요하지 않습니다.
