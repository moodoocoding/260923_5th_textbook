**텍스트 원고의 내용 정확성, 맞춤법과 문장 표현, 학생 활동 설계의 타당성을 중심으로 검토합니다.** 오류를 지적하는 데서 끝내지 않고, **해당 원문·판단 근거·수정안·연결된 원고 위치**를 기록해 실제 교과서 제작에 사용할 수 있도록 하겠습니다.

검토 범위 조정: 2026-09-23 사용자 지시에 따라 **이미지 시안은 검토하지 않습니다.** 원고와 시안의 차이, 시안에만 있는 문구, 그림의 구현 상태·디자인·해상도는 이번 검토의 오류나 보류 사항으로 집계하지 않습니다.

# 5학년 인공지능 리터러시 6단원 교과서 원고 검토 계획안

## 1. 검토 목적과 범위

### 가. 검토 목적

교과서에 실릴 설명과 활동에 사실적 오류나 오개념을 유발하는 표현이 없는지 살피고, 맞춤법·띄어쓰기·문법을 점검합니다. 아울러 초등학교 5학년 학생이 내용을 이해하고, 제시된 자료와 안내만으로 활동을 수행할 수 있는지 검토합니다.

**문장이 자연스럽더라도 내용이 부정확하면 수정 대상으로 보고, 내용이 정확하더라도 학생이 다르게 이해할 가능성이 크면 별도의 보완 대상으로 다룹니다.**

### 나. 검토 대상

검토 대상은 「초등5_인공지능리터러시_6단원_02~04차시_김태호_0923.pdf」의 **텍스트 원고 9개 쪽: 1·2·3·5·7·9·11·13·15쪽**입니다. 아래 쪽수는 PDF 파일의 페이지 순서이며, 각 페이지 안의 왼쪽·오른쪽 지면을 구분합니다. 4·6·8·10·12·14·16쪽의 이미지 시안은 검토 대상에서 제외합니다.

| 구분 | 검토 범위 | 검토 방법 |
|---|---|---|
| 단원 도입 | PDF 1~2쪽 | 단원명, 소단원 안내, 학습 방향, 도입 이야기, 사전 경험 문항에 본문과 동일한 아홉 영역의 정밀 검토 적용 |
| 02차시 | PDF 3·5쪽 | 원고 한 쪽의 좌우 지면을 한 묶음으로 검토 |
| 03차시 | PDF 7·9·11쪽 | 원고 한 쪽의 좌우 지면을 한 묶음으로 검토 |
| 04차시 | PDF 13·15쪽 | 원고 한 쪽의 좌우 지면을 한 묶음으로 검토 |

검토 범위에는 원고에 적힌 **학습 목표, 소제목, 활동 지시문, 보기, 선택지, 표, 빈칸, 대사·말풍선 문안, 날개단, 용어 풀이, 정리 문장**까지 포함합니다. 삽화 설명은 학생용 문장과 구분하여, 지시 자체의 내용 정확성·학습 활동과의 연결·필요한 정보가 지정되어 있는지를 검토합니다. 아직 제작되지 않은 그림의 구현 여부나 원고에 없는 그림 속 글자를 추정하여 평가하지 않습니다.

페이지 위치는 혼동하지 않도록 **‘PDF 7쪽 오른쪽, 활동 2번’**과 같이 기록합니다.

### 다. 기준본과 수정본 관리

검토 착수 시 기준 PDF의 **파일명, 수정 일시, 전체 쪽수, 버전 식별자**를 기록합니다. 이후 수정본은 별도 버전으로 구분하고, 지적한 원문이 어느 기준본에 있었는지와 어느 반영본에서 재검토했는지 연결합니다. 지면 이동으로 쪽수가 달라지면 이전 위치와 새 위치를 함께 남깁니다.

같은 이름의 HWP는 편집 원본 후보로 관리하며, PDF와 내용이 같다고 미리 가정하지 않습니다. HWP에 수정을 반영하는 경우에는 해당 HWP 버전과 다시 출력한 PDF 버전을 연결하고, 출력된 텍스트 원고에서 반영 여부를 확인합니다.

현재 제공되지 않은 01차시 본문은 직접 검토한 것으로 처리하지 않습니다. 도입부에 제시된 01차시 안내와 단원 전체의 완전한 대응 여부는 해당 원고가 필요한 확인 사항으로 남깁니다.

## 3. 이 원고에서 우선 검토할 내용

아래 항목은 오류를 확정한 결과가 아니라, **현재 원고의 소재와 활동을 바탕으로 설정한 우선 검토 질문**입니다.

### 가. 02차시: 책임 있는 공유에 관한 설명과 판단 기준

현재 원고는 도서관 안내 포스터를 중심으로 사실 확인, 개인정보 보호, 출처 표시, 인공지능 활용 표시를 다룹니다. (PDF 3쪽 왼쪽 포스터 설명·오른쪽 「공유하기 전에 확인해요」)

**첫째, 서로 다른 개념이 섞여 있지 않은지 검토합니다.** 출처를 밝히는 일, 이용 허락을 받는 일, 개인정보를 보호하는 일, 인공지능 활용 사실을 알리는 일이 각각 어떤 의미로 설명되는지 살핍니다. 교육적으로 권장하는 행동을 예외 없는 법적 의무처럼 표현하고 있지는 않은지도 검증 대상으로 둡니다.

**둘째, 공유 여부를 판단할 정보가 충분한지 검토합니다.** 원고의 ‘바로 공유해요 / 다시 확인해요’ 활동에서, 제시된 조건만으로 공유 여부를 결정할 수 있는지 학생 입장에서 풀어 봅니다. 특정 표시를 했다는 사실만으로 다른 조건까지 충족되었다고 가정해야 하는 문항은 없는지 살핍니다. (PDF 5쪽 오른쪽 「책임 있게 나누어 보아요」의 공유 판단 활동)

**셋째, 의도적으로 잘못 만든 사례와 교재 자체의 오류를 구분합니다.** 포스터의 잘못된 시간이나 빠진 표시처럼 학생이 찾아야 하는 요소를 교재의 오류로 처리하지 않습니다. 대신 학생이 무엇을 근거로 잘못되었다고 판단할 수 있는지, 필요한 안내나 비교 자료가 제공되는지를 검토합니다.

### 나. 03차시: 인공지능의 사회적 영향과 사례 설명

현재 원고에는 서빙 로봇·자동 결제기를 언급하는 설명, 의사 사진을 활용한 학습 데이터 활동, 추천 영상 활동이 포함되어 있습니다. (PDF 7쪽 왼쪽 「인공지능이 우리 삶에 미치는 영향」·추천 활동, 오른쪽 「인공지능도 잘못 판단할 수 있어요」)

**인공지능과 자동화의 구분**을 우선 검토합니다. 사례에 등장하는 기계나 서비스가 어떤 기능 때문에 인공지능의 사례로 제시되는지, 그 근거가 본문이나 삽화 설명에 드러나는지 살핍니다.

**학습 데이터와 판단 결과의 관계**도 세밀하게 검토합니다. 사진을 보고 특징을 예상하는 활동이 실제 인공지능 학습을 이해하도록 돕는지, 특정 학습 자료를 사용하면 반드시 하나의 결과가 나온다고 받아들이게 하지는 않는지 검토합니다. 추천 영상 활동에서도 추천의 편리함과 접하는 정보의 범위에 관한 설명이 활동의 결론과 연결되는지 살핍니다.

또한 원고에는 가짜 사진의 단서를 찾는 활동과 챗봇의 조언을 따르려는 학생의 사례가 제시되어 있습니다. (PDF 9쪽 왼쪽 가짜 사진 활동·오른쪽 민서와 챗봇 사례)

**거짓 정보 판단 활동**에서는 사진의 외형적 단서를 살피는 것과 출처·사실 여부를 검증하는 것이 어떻게 연결되는지 검토합니다. 학생이 ‘이상한 부분이 보이지 않으면 진짜’라고 결론 내리도록 구성되어 있지는 않은지 살핍니다.

**챗봇 과의존과 일의 변화**에서는 인공지능의 역할을 사람의 이해나 감정과 혼동하게 하는 표현이 없는지, 학생이 선택할 수 있는 대응이 구체적인지 검토합니다. 일의 변화 활동은 분류 기준이 명확한지, 서로 다른 분류에 합리적인 이유가 있을 때 이를 인정할 수 있도록 구성되어 있는지 살핍니다. (챗봇: PDF 9쪽 오른쪽, 일의 변화: PDF 11쪽 왼쪽 「인공지능이 바꾼 일터를 살펴보아요」)

### 다. 04차시: 자원 사용에 관한 설명과 토큰 활동

현재 원고는 질문이 전달되고 답이 돌아오는 과정, 데이터 센터의 전기·물 사용, 탄소 발자국을 설명하고 있습니다. (작동 과정: PDF 13쪽 왼쪽 「인공지능도 자원을 사용해요」, 자원과 탄소 발자국: PDF 15쪽 왼쪽 「인공지능 뒤의 자원을 한눈에 보아요」)

**자원 사용의 주체와 범위**를 검토합니다. 어떤 과정에서 어떤 자원이 사용되는지, 특정 운영 방식에 해당하는 설명을 모든 인공지능에 적용하고 있지는 않은지 살핍니다. ‘많은’, ‘아주 많은’ 등의 표현은 비교 기준이나 설명 맥락이 충분한지도 검토합니다.

원고의 자원 예산 활동에는 행동별로 0~3토큰을 부여하고, 10토큰 안에서 글과 그림을 만드는 조건이 제시되어 있습니다. (PDF 15쪽 오른쪽 「인공지능 자원 예산 챌린지를 해 봅시다」)

**토큰의 의미와 계산 규칙**을 별도로 검토합니다. 활동용 토큰이 실제 자원 소비량이나 인공지능의 다른 ‘토큰’ 개념과 혼동되지 않는지, 카드별 비용과 합계 계산 방식이 일치하는지 살핍니다. 처음 생성하지 않고 수정 카드만 고르는 경우 등도 대입하여, 활동 조건에 빈틈이 없는지 검토합니다.

**활동의 결론과 차시의 핵심 메시지**도 대조합니다. 원고의 “필요한 도움을 알맞게 받는 것”이라는 방향과 실제 활동에서 좋은 선택으로 유도하는 행동이 일치하는지를 살핍니다. (PDF 15쪽 오른쪽 「필요한 만큼 알맞게 사용해요」 도입 문단)

## 4. 검토 절차와 진행 순서

### 가. 진행 원칙

**한 쪽의 텍스트 원고에 실린 좌우 지면을 한 묶음으로 세밀하게 검토한 뒤 다음 묶음으로 넘어갑니다.** 먼저 PDF 3쪽을 시범 검토해 결과의 깊이와 검토 방식의 적절성을 평가합니다. 전체 원고를 한꺼번에 고쳐 제시하지 않고, 검토 결과와 수정 결정이 구분되도록 진행합니다.

정밀 검토에 앞서 텍스트 원고 9개 쪽의 제목·학습 목표·본문·활동 대응을 훑어 **큰 누락·중복·원문 내부 불일치**를 목록화합니다. 해결되지 않은 항목을 추적하면서 다른 원고의 검토를 계속합니다.

현재 원고에서 우선 재확인할 사항은 다음과 같습니다.

- PDF 13쪽 오른쪽 「공유하기 전에 확인해요」는 PDF 3쪽 오른쪽의 공유 관련 내용을 반복합니다. 04차시 안에서 이 반복이 의도된 것인지, 다른 원고가 필요한지 확인합니다.
- PDF 1·7쪽의 03차시명 「인공지능 사용할 때 한 번 더 생각하기」와 PDF 2쪽 소단원 3 안내의 「인공지능 사회 문제 깊이 탐구하기」를 대조하여 원고 안의 명칭을 정리합니다.

위 항목은 원고의 구조를 확인하기 위한 착수 목록이며, 최종 수정 방향을 확정한 판정은 아닙니다.

| 단계 | 실시 내용 | 단계별 산출물 |
|---|---|---|
| **1단계: 기준본·전체 구조 확인** | 기준본 버전과 위치 표기 방식 설정, 학생용 내용과 제작 지시 구분, 텍스트 원고의 누락·중복·내부 대응 확인, 도입부의 전체 방향 파악 | 기준본 기록, 원고별 점검표, 구조상 확인 사항 목록, 공통 표기표 초안 |
| **2단계: 첫 묶음 정밀 검토** | PDF 3쪽 원고를 대상으로 아홉 영역 검토, 모든 활동의 풀이·허용 답안 기록, 외부 근거 조사, 문장별 어문 교정, 원문 내부 대조, 검토 방식 평가 | 첫 묶음 검토표, 활동 검증표, 원고별 완료 기록, 계획 적용 평가 |
| **3단계: 나머지 범위 정밀 검토** | PDF 5쪽 → 7쪽 → 9쪽 → 11쪽 → 13쪽 → 15쪽 → 1~2쪽 순으로 동일한 아홉 영역과 검증 절차 적용 | 묶음별 검토표, 활동 검증표, 누적 수정 목록, 공통 표기표 갱신 |
| **4단계: 단원 전체 연결 검토** | 도입부와 본문 대조, 목표별 대응 활동과 확인할 응답·수행 정리, 용어·인물·차시명·설명 수준의 일관성 및 차시 간 중복·누락 점검 | 단원 공통 쟁점표, 목표와 활동의 대응표, 공통 표기표 |
| **5단계: 수정 결정과 반영 대조** | 제안별 채택·미채택·보류와 사유 기록, 큰 오개념 위험이 있는 권고의 처리 확인, 채택된 수정의 원문 반영 및 버전 대조 | 수정 이력표, 반영본 기록, 미해결 항목표 |
| **6단계: 최종 교정** | 수정된 전체 지면 재독, 문장별 어문 교정과 공통 표기 재점검, 활동 재풀이, 수정으로 생긴 누락·불일치 점검 | 지면별 최종 점검 기록, 재검토일이 포함된 최종 결과표 |

단원 도입부는 시작 단계에 읽어 전체 방향을 파악하고, 3단계에서 본문과 동일하게 정밀 검토합니다. 이후 **본문의 수정 방향이 정해지면 다시 대조**합니다. 처음 읽기나 전체 연결 확인만으로 도입부의 내용·어문·활동 검토를 완료 처리하지 않습니다.

### 나. 근거를 검증하는 방법

내용의 정확성을 판단할 때에는 해당 문장을 먼저 특정하고, 무엇을 검증해야 하는지 질문으로 바꾼 뒤 근거를 찾습니다.

| 검증 대상 | 우선 사용할 근거 |
|---|---|
| 맞춤법·띄어쓰기·표준어 | 국립국어원의 어문 규범과 사전 자료 |
| 인공지능의 개념·기술적 설명 | 관련 연구 원문, 공식 기술 문서, 공신력 있는 기관의 원자료 |
| 개인정보·저작권·이용 의무 | 검토 시점의 법령과 담당 기관의 공식 안내 |
| 환경·자원·수치·비교 | 조사 범위와 산정 조건이 제시된 보고서 또는 연구 원문 |
| 교육과정과의 연계 | 적용할 교육과정, 과목의 성취기준, 집필·편집 지침 |

외부 근거는 **기관·저자, 문서명, 실제로 열 수 있는 URL 또는 파일 위치, 해당 쪽·절, 발표·개정 시점, 확인일, 적용 조건, 해당 문장을 뒷받침하는 내용**을 함께 기록합니다. 법령은 관련 조항과 시행일도 확인합니다. 문서 내부를 근거로 삼을 때에는 기준본 버전과 PDF 쪽수·좌우·항목을 적습니다. 근거를 확보하지 못한 항목은 추정으로 고치지 않고 ‘판단 보류’로 남깁니다.

교육과정 적합성이나 수업 시간 내 활동 가능성은 관련 성취기준과 배정 시간 등 필요한 자료가 확보된 범위에서 판단합니다.

### 다. 모든 활동의 검증과 학년 적합성 확인

사전 경험 문항, 본문 활동, 정리 문항을 포함한 **모든 활동과 하위 문항**에 검토용 풀이 기록을 남깁니다. 최소 기록은 예상 답 또는 허용 답안 범위, 판단 근거, 제공된 정보만으로 해결 가능한지입니다. 토론·성찰·경험 문항에는 단일 정답을 강요하지 않고, 지시에 맞는 응답의 조건과 학습 목표를 확인할 수 있는 설명·수행을 기록합니다.

검토자는 원고에 제시된 자료와 명시된 선수지식을 기준으로 풀어 봅니다. 제작 지시로 제공하도록 정한 자료는 그 조건을 가정해 활동 설계를 검증하고, 실제 완성 지면에서 확인한 것과 구분합니다. 교사의 추가 설명이나 검토자의 전문지식이 있어야 풀리는 경우에는 필요한 안내를 구체적으로 남깁니다. 한 번에 수행해야 하는 지시 수, 결론까지 필요한 추론 단계, 예시와 요구 응답의 분량도 확인합니다.

문항을 풀기 전에 요구하는 수행이 ‘확인할 대상 찾기’, ‘주어진 가정에 따라 판단하기’, ‘실제 자료와 대조하기’, ‘직접 고치거나 표시하기’ 중 무엇인지 기록합니다. 의도적으로 잘못 제시한 사례, 가정으로 주어진 사실, 아직 제공되지 않은 정보를 구분하여 활동 성립 여부를 판단합니다.

선택·계산·순서가 있는 활동은 대표 풀이와 조건이 어긋날 수 있는 경우를 함께 대입합니다. 자원 예산 활동에서는 합계 계산, 생성과 수정의 선후 관계, 반복 선택 가능 여부, 필수 선택 조건 등을 확인합니다.

해당 활동에 필요한 기기·자료·계정·모둠 구성·교사 준비 등이 있으면 기록합니다. 활동의 지시·자료 자체에 결함이 있는 경우와 수업 환경·배정 시간을 확인하지 못한 경우를 구분합니다. 문서만으로 판단한 학년 적합성은 실제 학생 대상 검증 결과와 구분해 표시합니다.

### 라. 어문 교정과 공통 표기 관리

각 묶음의 내용을 검토한 뒤 **원고의 본문·지시문·보기·선택지·표·말풍선 문안·용어 풀이를 문장 또는 문구 단위로 다시 읽으며 어문 교정**을 합니다. 수정 후 텍스트 원고 전체에서 같은 절차를 반복합니다.

공통 표기표에는 인공지능/AI의 사용 방식, 단원·차시명, 인물 이름, 용어, 본문의 종결 어미, 활동 지시문의 형식, 숫자·단위·문장 부호 등을 기록합니다. **규범상 오류, 규범상 허용되는 표기, 편집상 통일 사항**을 구분하며, 허용되는 표현을 다른 방식으로 통일하는 제안을 맞춤법 오류로 표시하지 않습니다.

출판사의 집필·편집 지침이 있으면 그 적용 범위를 확인합니다. 지침이 없으면 표기안을 제안하고 채택 여부를 기록하되, 규범상 판단과 편집상의 선택을 구분합니다.

## 5. 오류 판정과 수정 제안 방식

검토 결과는 다음 네 가지로 구분합니다.

| 판정 | 적용 기준 | 처리 방식 |
|---|---|---|
| **수정 필수** | 근거로 확인된 사실 오류, 명백한 어문 오류, 활동을 성립하지 못하게 하는 조건 누락, 원문 내부의 의미상 모순 | 문제 위치와 근거를 제시하고 최소 수정안 작성 |
| **수정 권고** | 틀렸다고 단정하기는 어렵지만 오개념이나 오해를 유발할 가능성이 큰 설명, 지나치게 모호한 지시 | 예상되는 오해와 보완 방향을 함께 제시 |
| **선택적 개선** | 의미와 정확성에는 문제가 없지만 가독성이나 표현을 개선할 수 있는 부분 | 오류 교정과 분리하여 제안 |
| **판단 보류** | 출처, 집필 의도, 활동에 필요한 조건, 적용 기준 등이 부족한 부분 | 부족한 자료와 추가로 판단해야 할 사항 명시 |

**원문이 직접 한 주장과, 학생의 오해를 예방하기 위한 보완을 구분하여 기록합니다.** 원문이 주장하지 않은 내용을 가정해 사실 오류로 판정하지 않습니다. 학생용 문구의 결함과 제작 지시에 추가할 조건도 구분합니다.

띄어쓰기나 글자 오류는 추출된 텍스트만으로 판정하지 않고 **텍스트 원고가 실린 PDF 지면**과 대조합니다. 원문 판독이 불확실한 부분은 추측해서 교정하지 않고 위치를 남깁니다. 이는 이미지 시안 검토를 의미하지 않습니다.

수정안은 원래 의도를 살리는 최소 수정부터 검토합니다. **단어 교체나 문장 보완만으로 해결되지 않는 개념 설명·활동 결함에는 재구성안을 함께 제안**하고, 바뀌는 학습 내용·활동 조건·제작 지시의 범위를 명시합니다.

수정 권고 중 **오개념·오해의 위험이 큰 항목**은 별도로 표시합니다. 이를 미채택할 때에는 유지 근거와 남는 위험, 필요하면 보완 설명을 기록합니다. 중요한 위험이 미해결 상태이면 최종 결과에 ‘출판 전 추가 판단 필요’로 남기며, 단순한 문체 개선의 미채택과 구분합니다.

## 6. 검토 결과 기록 양식

각 검토 결과 문서는 **제목·검토일 다음에 ‘먼저 보는 수정표’를 배치**합니다. 검토 범위, 종합 판단, 상세 근거보다 먼저 실제로 어디를 어떻게 수정할지 확인할 수 있게 합니다.

| 구분·검토 번호 | 위치 | 현재 원문 | 수정·추가안 | 수정 이유 |
|---|---|---|---|---|
| 필수 / 권고 / 선택 / 보류 및 고유 번호 | PDF 쪽수·좌우·항목 | 원문 그대로 인용 | 바로 반영할 수 있는 문안 또는 구체적인 추가·삭제 지시 | 핵심 이유 한 문장 |

반복 교정은 실제 위치별로 행을 나누고, 문장을 새로 넣는 경우에는 ‘추가’라고 명시합니다. 수정안에서 바뀌는 부분을 강조하며, 함께 바꿔야 하는 연결 문장과 여러 제안이 겹치는 위치의 처리 방법도 적습니다. 권고 중 오개념 위험이 큰 항목은 ‘권고·중요’로 표시하고, 보류 항목은 필요한 확인 사항을 기록합니다. 요약표와 상세 검토에 같은 검토 번호를 사용하며, 제안과 원본 반영 여부를 구분합니다.

### 가. 개별 문제와 수정 이력

검토 사항은 문제 하나당 항목 하나로 기록합니다. 같은 문제가 여러 곳에 반복되면 공통 문제로 묶되, 해당 위치를 빠짐없이 남깁니다.

| 기록 항목 | 기록 내용 |
|---|---|
| **검토 번호** | 문제를 추적할 수 있는 고유 번호 |
| **기준본** | 지적한 원문이 실린 파일명·버전·수정 일시 |
| **위치** | PDF 쪽수, 왼쪽·오른쪽, 소제목, 문단 또는 활동 번호 |
| **검토 대상 원문** | 문제가 있는 문장이나 문항을 수정하지 않고 인용 |
| **검토 영역·판정** | 내용 정확성, 맞춤법, 활동 타당성 등의 영역과 수정 필요 수준, 큰 오개념 위험 해당 여부 |
| **문제점** | 무엇이 잘못되었거나 모호한지, 학생이 어떻게 오해할 수 있는지 설명 |
| **판단 근거** | 어문 규범, 외부 자료, 문서 내부의 모순, 실제 풀이 결과 등 |
| **수정안** | 원래 의도와 구성을 유지하는 최소 수정 문장·활동 조건, 필요한 경우 재구성안과 변경 범위 |
| **원문 내 연결 사항** | 함께 바꿔야 할 본문, 말풍선 문안, 표, 보기, 제작 지시와 그 이유 |
| **연결된 수정 위치** | 같은 수정이 필요한 다른 페이지·본문·날개단·정리 문장 |
| **처리 상태** | 제안, 채택, 미채택, 보류, 반영 완료, 재검토 완료 |
| **결정 근거·남은 사항** | 채택·미채택·보류 사유, 큰 오개념 위험이 있는 권고를 유지하는 근거와 남는 위험, 필요한 추가 자료 |
| **반영본·재검토 기록** | 반영한 파일명·버전, 변경된 경우 새 위치, 원문 수정 확인 결과, 재검토일 |

### 나. 지면별 누락 방지 점검표

오류 목록과 별도로 **문제 없는 부분에도 완료 기록을 남깁니다.** 텍스트 원고 9개 쪽의 좌우 지면에 있는 학습 목표·본문·활동·표·말풍선 문안·날개단·용어 풀이·제작 지시를 실제 구성에 맞게 나눠 등록합니다. 한 항목의 문제를 기록했다는 이유만으로 해당 원고 전체를 완료 처리하지 않습니다.

| 대상 ID | 기준본·PDF 위치 | 점검 대상 | 아홉 영역별 상태 | 전체 상태 | 연결된 검토 번호·보류 사유 | 검토일 |
|---|---|---|---|---|---|---|
| 작성 시 부여 | 버전·쪽수·좌우·항목 | 실제 지면의 대상명 | ①~⑨ 각각 표시 | 아래 상태 중 선택 | 해당 없으면 ‘없음’ | 실제 검토일 |

- **미검토:** 아직 확인하지 않은 항목입니다. 실제 검토 전의 기본 상태입니다.
- **검토 완료—문제 없음:** 적용되는 검토 영역을 확인했고 발견한 문제가 없는 항목입니다.
- **검토 완료—수정 사항 있음:** 검토 결과를 기록했으며 관련 문제 번호가 있는 항목입니다. 수정 반영 완료를 뜻하지 않습니다.
- **판독·판단 보류:** 읽을 수 없거나 판단 자료가 부족한 항목입니다. 부족한 자료와 다음 확인 사항을 적습니다.
- **해당 없음:** 특정 검토 영역이 적용되지 않거나 해당 지면에 구성 요소가 없는 경우이며, 이유를 적습니다.

최종 검토 시에는 각 대상의 완료 기록을 최신 반영본 기준으로 갱신합니다. 이 양식 자체를 작성한 것은 실제 교과서 검토를 완료한 것으로 보지 않습니다.

### 다. 모든 활동의 검토용 풀이 기록

| 기록 항목 | 기록 내용 |

| **예상 답·허용 범위** | 정답, 가능한 복수 답과 이유, 또는 토론·성찰·경험 문항의 적절한 응답 조건 |

| **해결 가능성·수행 부담** | 원고와 명시된 제작 조건으로 설계가 성립하는지, 지시 수·추론 단계·예시·요구 응답 분량이 적절한지, 수업 환경 미확인 여부 |

모든 활동에는 위 항목의 최소 기록을 남기고, 문제가 있거나 풀이가 복잡한 활동은 상세하게 기록합니다. 실제 풀이 과정에서 발견한 오류는 개별 문제표의 검토 번호와 연결합니다.

## 7. 최종 검토 완료 기준

완료 여부는 총점보다 **남아 있는 문제의 성격과 해결 상태**를 기준으로 판단합니다.

| 완료 기준 | 충족 조건 |
|---|---|
| **검토 범위의 누락이 없음** | 도입부를 포함한 텍스트 원고 9개 쪽의 아홉 영역 점검 기록이 있고, 보기·날개단·말풍선 문안·표·제작 지시까지 미검토 항목이 없음 |
| **수정 필수 항목이 해결됨** | 확인된 내용 오류, 어문 오류, 활동 결함, 의미상 불일치가 수정되고 재검토됨 |
| **큰 오개념 위험에 대한 결정이 확인됨** | 해당 수정 권고의 채택 여부와 미채택 시 유지 근거·남는 위험이 기록되어 있고, 중요한 오개념 위험에 대한 미해결 판단 사항이 없음 |
| **핵심 사실의 근거가 확보됨** | 중요한 설명을 뒷받침하는 근거가 기록되어 있으며, 출판 판단에 영향을 주는 보류 항목이 해결됨 |
| **활동이 성립함** | 모든 활동·하위 문항에 예상 답 또는 응답 범위와 풀이 근거가 있고, 지시·자료·선택 조건·선수지식이 맞으며 수정본 재풀이에서 미해결 모순이 없음 |
| **어문 교정과 표기 통일이 확인됨** | 문장·문구 단위 교정과 원문 PDF 지면 대조를 마쳤고, 공통 표기표에서 채택한 기준의 적용 여부를 확인함 |
| **원문 내부의 내용이 대응함** | 채택된 수정이 연결된 본문·활동·표·용어 풀이·제작 지시에 반영되고, 원문 내부 불일치가 해결됨 |
| **최신 반영본에서 재확인됨** | 개별 수정의 반영본 버전·새 위치·재검토일이 기록되고, 최종 보고서와 실제 확인한 파일 버전이 일치함 |
| **수정 후 새 오류가 없음** | 바뀐 문장으로 인해 다른 활동, 용어 풀이, 표, 정리 문장에 새로운 불일치가 생기지 않았음 |

최종 보고서에는 **기준본과 최종 반영본 버전, 검토한 범위, 해결한 항목, 미채택한 중요 권고와 이유, 남은 보류 사항, 추가로 필요한 자료**를 명시합니다. 원고 검토와 수정 제안까지 마친 상태, 수정 반영 후 재검토까지 마친 상태, 출판 전 추가 판단이 필요한 상태를 구분합니다. 수정 반영본이 제공되지 않았다면 제안 작성 완료와 반영·재검토 완료를 혼동하지 않습니다.
