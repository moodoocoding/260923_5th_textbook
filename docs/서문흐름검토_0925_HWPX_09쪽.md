# 0925 HWPX 9쪽 서문·본문 흐름 검토

- 검토 대상: `초등5_인공지능리터러시_6단원_02~04차시_김태호_0925.hwpx`
- 검토 기준: 서문과 뒤따르는 개념·사례·활동의 논리적 연결, 초등학교 5학년 교재로서의 적절성
- 제외 항목: 삽화 설명, 여백 등 편집용 문구

| 우선순위 | 쪽·위치 | 현재 문구 또는 상태 | 수정안 | 수정 이유 |
|---|---|---|---|---|
| 중요 | 오른쪽 자원 예산 활동 | 카드별 토큰 비용이 제시되지 않음 | 각 카드에 토큰 비용을 명시 | 10토큰 안에서 카드를 선택하고 합계를 계산하는 활동을 현재 정보만으로 수행할 수 없음 |
| 오류 | 오른쪽 `나의 생각 카드` | `인공지능의 대답을 듣고 내 생각을 더해 완성한다.ㄱ` | `인공지능의 대답을 듣고 내 생각을 더해 완성한다.` | 불필요한 글자 `ㄱ`이 붙어 있음 |
| 확인 | 오른쪽 실천 약속 | 추출 문구는 `나는 인공지능을 사용할 때 하겠습니다`로 이어짐 | 지면에 학생이 쓸 공간이 없다면 `나는 인공지능을 사용할 때 __________________ 하겠습니다.`처럼 빈칸 표시 | 쓰기 공간이 보이지 않으면 문장이 미완성으로 읽힘 |

## 판단

- 왼쪽 페이지는 `데이터 센터의 계산 → 전기와 물 사용 → 탄소 발자국 가능성`의 순서로 자원 사용과 환경 영향을 설명한다. 서문에서 예고한 내용이 세 항목으로 분명하게 펼쳐져 논리적이고 적절하다.
- 오른쪽 페이지는 `자원을 많이 사용할 수 있음 → 10토큰 안에서 선택하기 → 사용량 계산하기 → 불필요한 요청 줄이기 → 실천 약속하기`로 이어진다. 개념을 실제 선택 활동으로 바꾸는 구조는 매우 좋다.
- 다만 토큰 비용이 없으면 활동 자체를 수행할 수 없다. 서문과 활동의 논리적 연결은 좋지만, 현재 상태의 활동 완성도는 미흡하다.
- 종합적으로 내용 방향은 적절하며, 토큰 비용 입력과 오탈자 수정이 필수다.
