## 판단

- 왼쪽 페이지는 `직업 변화 소개 → 인삼 농사 사례 → 다른 직업으로 확장 → 친구와 판단 비교`로 이어져 서문과 활동의 연결이 좋다.
- 오른쪽 페이지는 5~7쪽에서 살펴본 추천, 치우친 판단, 거짓 정보, 과의존, 직업 변화를 다시 모은 뒤 `영향과 실천 방법 쓰기 → 핵심 내용 점검`으로 정리한다. 차시 마무리로 적절하다.
- 수정된 서문은 이전보다 쉽고, 바로 아래 다섯 가지 선택 항목과도 잘 연결된다. 다만 추천 영상과 과의존의 인과관계가 한 문장에 묶이지 않도록 분리하면 더 정확하다.
- 종합적으로 흐름과 내용은 적절하며, 두 문장의 의미만 조금 더 분명히 하면 된다.
