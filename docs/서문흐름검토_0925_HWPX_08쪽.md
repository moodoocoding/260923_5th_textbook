## 판단

- 왼쪽 페이지는 `화면에 결과가 나타남 → 화면 밖의 계산 과정 질문 → 데이터 센터로 이동하고 처리되는 과정 → 자원이 필요하다는 결론`으로 전개된다. 질문에서 과정 설명으로 이어지는 흐름이 자연스럽다.
- 오른쪽 페이지는 `반복 생성은 자원을 더 사용함 → 민준과 서아의 사용 방법 비교 → 횟수와 자원 사용 판단 → 개선 방법 생각하기`로 이어져 서문과 활동이 직접 대응한다.
- 9쪽에서 전기·물·탄소 발자국을 구체적으로 설명하므로 8쪽은 자원 사용의 원리를 소개하는 단계로 적절하다.
- 종합적으로 흐름은 좋다. 다만 인터넷 기반 서비스라는 범위를 밝혀 사실관계를 정확히 해야 한다.
